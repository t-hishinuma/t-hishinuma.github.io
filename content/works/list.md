## 💻 Software

*   📦 **[monolish](https://github.com/ricosjp/monolish)**
    **MONO**lithic **LI**near equation **S**olvers for **H**ighly-parallel architecture. 
    *(Created during my tenure at [RICOS Co. Ltd.](https://www.ricos.co.jp/))*

*   🚀 **[DD-AVX_v3](https://github.com/t-hishinuma/DD-AVX_v3)**
    Library of High Precision Sparse Matrix Operations Accelerated by SIMD AVX.
    *(Read the [v1.0 release blog](https://hishinuma-t.dev/posts/tools/dd-avx_v10/))*

*   📊 **[numa_benchmark](https://github.com/t-hishinuma/numa_benchmark)**
    NUMerical linear Algebra Benchmark (Docker supported).

*   ⚙️ **[Xev-GMP-Web](http://xev.arch.is.tohoku.ac.jp/XevWeb/Xev-GMP-Web.html)**
    A tool that converts C source code using `double` variables into C source code using the GNU GMP library.

*   🧩 **[Lis_DD_AVXkernels](https://github.com/t-hishinuma/Lis_DD_AVXkernels)**
    LisのDD機能を AVX, AVX2 に拡張する差分およびマージスクリプト。
